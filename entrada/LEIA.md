# Solte aqui o PDF de uma fazenda nova

Clique em **Add file → Upload files**, solte o one-pager e salve.

Em poucos minutos o robô recorta as fotos, lê o texto e abre uma proposta de
alteração com a ficha pronta para você revisar. Nada vai ao ar sozinho.

Os PDFs já processados são movidos para `processados/`.
